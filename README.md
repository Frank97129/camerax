# camerax

Custom CameraX module based on PictureSelector camerax, updated to AndroidX CameraX 1.4.2.

## Usage

Add JitPack:

```kotlin
dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
        maven("https://jitpack.io")
    }
}
```

Add dependency:

```kotlin
implementation("com.github.Frank97129:camerax:<tag>")
```
